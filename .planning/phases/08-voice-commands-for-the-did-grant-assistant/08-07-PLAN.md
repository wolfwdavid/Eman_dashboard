## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-14 | Information Disclosure | microphone left open | mitigate | Push-to-talk only (D-13); every cancel path (Escape, chat close, hidden tab, destroy, typed send) stops recognizer/tracks; Playwright asserts tracks stopped |
| T-08-28 | Information Disclosure | audio persisted client-side | mitigate | Blobs are held in memory only, never written to storage, never logged; discarded on cancel |
| T-08-29 | Denial of Service | endless recording / hung upload | mitigate | 18 s recorder cap, 20 s transcribe timeout with AbortController |
