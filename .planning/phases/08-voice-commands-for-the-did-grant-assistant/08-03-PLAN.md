## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> browser vendor speech service | Audio leaves the device (Web Speech); disclosed by the D-16 notice in plan 08 |
| browser -> agent /chat/transcribe | Recorded audio uploaded to the configured Whisper backend |
| server response -> widget | Transcript text returned by the server is untrusted |
| localStorage -> widget | Stored preference values are untrusted strings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-14 | Information Disclosure | mic left on / audio retained | mitigate | startRecording stops every MediaStream track on stop, cancel and auto-stop; cancel discards chunks; tests assert track.stop() calls |
