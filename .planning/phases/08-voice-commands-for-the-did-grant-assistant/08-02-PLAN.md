<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet client -> POST /chat/transcribe | Unauthenticated upload (D-05), body, Content-Type, Content-Length, forwarded-IP headers are all attacker controlled |
| handler -> voice.transcribe -> Whisper backend | Uploaded bytes are passed to ffmpeg/PyAV or a hosted API |
| handler -> filesystem | Temp file written under the OS temp dir |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Spoofing | client_ip / rate-limit key | mitigate | Honour CF-Connecting-IP and the rightmost X-Forwarded-For entry only when the socket peer is loopback/private; otherwise use the socket address; header values must parse as IP addresses |
| T-08-06 | Denial of Service | oversize upload | mitigate | Reject Content-Length > 1,048,576 with 413 before reading the body; set close_connection to avoid keep-alive desync; client auto-stop at 18 s keeps real clips far below the cap |
| T-08-07 | Denial of Service | request flood / Whisper cost | mitigate | Per-IP limiter 10 per 60 s (429 + Retry-After) evaluated before the body read; BoundedSemaphore(2) around Whisper with non-blocking acquire (503); ThreadingHTTPServer so polling never stalls; limiter memory bounded by pruning at 5000 keys |
| T-08-08 | Denial of Service | slow-loris / lying Content-Length | mitigate | Handler `timeout = 30` socket timeout |
| T-08-09 | Tampering | file suffix / path injection | mitigate | Suffix chosen only from the fixed _AUDIO_EXT map keyed by the validated MIME; client filename and any header-derived path component are never used; mkstemp creates the file |
| T-08-10 | Tampering | non-audio payload | mitigate | MIME allow-map (415); decoding is delegated to voice.transcribe, failures return a generic 502 |
| T-08-11 | Information Disclosure | error responses | mitigate | Fixed generic messages; exception text is logged server-side only; tests assert "boom" is not echoed |
| T-08-12 | Information Disclosure | residual audio on disk | mitigate | try/finally unlink after every request including failures; tests assert the file is gone |
| T-08-13 | Elevation of Privilege | missing auth on the public endpoint | accept | Owner decision D-05 keeps /chat and /chat/transcribe open; the existing CHAT_API_TOKEN check is reused unchanged and enforced when set; residual risk is Whisper cost, bounded by T-08-06/07 |
| T-08-SC | Tampering | pip installs | accept | No packages installed or added to requirements in this plan |
</threat_model>
