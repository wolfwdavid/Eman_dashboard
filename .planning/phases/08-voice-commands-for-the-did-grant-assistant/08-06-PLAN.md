<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transcript / typed text -> widget DOM | Untrusted text rendered in bubbles and the live region |
| transcript -> POST /chat | Spoken input forwarded to the existing public API |
| bot reply -> widget | Reply text from the agent rendered and (later) spoken |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-23 | Tampering (XSS) | transcript, confirmation and reply rendering | mitigate | Svelte text interpolation only; no {@html} anywhere in ChatWidget (acceptance grep); transcripts never used in selectors or innerHTML |
| T-08-24 | Denial of Service | oversized spoken question | mitigate | capTranscript limits to 500 characters before routing and before POST /chat |
| T-08-25 | Tampering | hijacking questions as commands | mitigate | Question guard in commands.ts (plan 01); open-grant ids validated in actions (plan 04) |
| T-08-26 | Denial of Service | flooding /chat via repeated voice questions | mitigate | busy flag blocks a second question while one is pending (busy string shown instead of sending) |
| T-08-27 | Information Disclosure | live region leaking interim speech | mitigate | Interim text never written to the live region; only final transcript + result |
| T-08-SC | Tampering | npm installs | accept | No packages added; frozen lockfile install only |
</threat_model>
